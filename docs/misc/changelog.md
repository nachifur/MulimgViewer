# 更新记录

## 未发布（v3.9.7 之后的变化）

- **多路视频浏览**。支持从目录或文件清单载入视频，并排查看同一帧。跳转到长视频中段时优先准备当前页，后台沿播放方向预取后续页面。
- **播放与缓存**。四档 Power mode 控制并行任务的资源预算。拆帧、算法处理、各算法拼接和最终合成可交错执行。内外两层缓存随浏览位置移动，播放间隔会参考拼接画面的实际供给速度。
- **算法对比**。可以并排查看原图和所选算法，也可以按布局容量展示多个算法。后台缓存处理图和拼接结果，便于反复查看同一页。
- **索引与定位**。索引表可按画面中的图像、页面或来源浏览，支持与主窗口双向定位、查看原始路径和视频帧路径，以及导出 Excel。
- **挑图与导出**。支持在后台按点击保存时的参数导出拼接图、选中图像和放大图。可分别设置显示与输出比例，选择 JPG、PNG 或 PDF，并暂停、继续批量保存。
- **设置与回归测试**。右侧设置区按功能折叠，重新打开时恢复上次配置。开发者可一键运行图像与视频回归测试并查看逐项报告。

- **安装与兼容性**。增加 PyPI 安装支持和 Linux 桌面入口，修复 macOS 上的兼容问题。
- **放大与标题**。放大图的显示比例与输出比例可分别设置。支持共享标题和显示 EXIF 信息，修复放大框位置及拼接间距问题。

操作示例见[图像与视频浏览](../resources/usage.md)，参数见[设置说明](../resources/settings.md)，测试方法见[开发指南](../dev/dev.md)。
